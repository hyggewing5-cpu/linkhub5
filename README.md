# ศูนย์รวมลิงก์ — GitHub Pages + ระบบสมาชิก

โครงสร้าง: เว็บ (GitHub Pages) ⇄ Google Apps Script Web App (API) ⇄ Google Sheet

## โฟลเดอร์
- `site/`  → อัปโหลดขึ้น GitHub (index.html, api-config.js, .nojekyll, admin/index.html)
- `apps-script/` → วางใน Apps Script ของชีต (code.gs, appsscript.json)

## 1) ฝั่ง Google (ทำครั้งเดียว)
1. เปิดชีต → ส่วนขยาย → Apps Script
2. วาง `code.gs` ทับไฟล์ Code.gs เดิมทั้งไฟล์ และวาง `appsscript.json` ทับของเดิม (Project Settings → Show "appsscript.json")
3. เลือกฟังก์ชัน `setup` → Run → อนุญาตสิทธิ์ แล้วดูรหัสผ่านผู้ดูแลหลักที่ Execution log
   (สร้างชีต `สมาชิก` และ `ประวัติเข้าใช้` ให้เอง และเพิ่มคอลัมน์ "การมองเห็น" ให้ชีตเดิมโดยไม่แตะข้อมูล)
   ลืมรหัส: รัน `resetAdminPassword`
4. Deploy → Manage deployments → แก้ไข (ดินสอ) → Version: **New version** → Deploy
   (ถ้ายังไม่เคย Deploy: New deployment → Web app, Execute as: Me, Who has access: Anyone)
5. ทดสอบ: เปิด URL `/exec` ในหน้าต่างไม่ระบุตัวตน ต้องเห็น `{"ok":true,"service":"linkhub",...}`

> แก้ code.gs ภายหลังต้อง New version ทุกครั้ง ไม่เช่นนั้นเว็บจะใช้โค้ดเก่า
> **อย่าแชร์ชีตแบบ "ทุกคนที่มีลิงก์"** เพราะชีต `สมาชิก` เก็บแฮชรหัสผ่านไว้ ให้แชร์เฉพาะแอดมิน

## 2) ฝั่ง GitHub
1. สร้าง repo แล้วอัปโหลดไฟล์ใน `site/` (รวม `.nojekyll` และโฟลเดอร์ `admin/`)
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save
3. เปิด `https://ชื่อผู้ใช้.github.io/ชื่อrepo/`  | หน้าแอดมิน: `.../admin/` หรือ `.../?page=admin`
4. ถ้าเปลี่ยน URL ของ Web app ให้แก้ `api-config.js` (GitHub cache ประมาณ 10 นาที)

## การใช้งานระบบสมาชิก
- ผู้เยี่ยมชม: เห็นเฉพาะรายการที่ตั้งเป็น "ทุกคน"
- สมาชิก: กด "สมัครสมาชิก" ใช้ได้ทันที เห็น "ทุกคน" + "เฉพาะสมาชิก"
- แอดมิน: เห็น/แก้ไขทั้งหมด จัดการสมาชิก (ตั้งสิทธิ์ ระงับ รีเซ็ตรหัส ลบ) และดูประวัติเข้าใช้ (ดาวน์โหลด CSV ได้)
- ชื่อผู้ใช้ `admin` = ผู้ดูแลหลัก ใช้รหัสที่ `setup()` สร้างให้
- ตั้งสิทธิ์การมองเห็นได้ที่ฟอร์มแก้ไขของ กลุ่ม / ลิงก์ / ข่าว / แท็บเมนู
- ตั้ง "รหัสสมัครของหน่วย" หรือปิดรับสมัครได้ในหน้าแอดมิน (แนะนำให้ตั้งรหัสเพื่อกันคนนอกสมัคร)
- การกรองตามสิทธิ์ทำที่เซิร์ฟเวอร์ รายการที่ไม่มีสิทธิ์จะไม่ถูกส่งไปเบราว์เซอร์เลย

## ข้อจำกัดที่ควรรู้
- ฮับซ่อนลิงก์ได้ แต่ไม่ได้ล็อกระบบปลายทาง ถ้าระบบนั้นไม่มีการยืนยันตัวตนของตัวเอง ใครรู้ลิงก์ก็เข้าตรงได้
- ประวัติเก็บ เวลา/ชื่อผู้ใช้/เหตุการณ์/อุปกรณ์ (Apps Script มองไม่เห็น IP)
- จำนวนรอบแฮชรหัสผ่าน `HASH_ROUNDS` ใน code.gs ตั้งตามความเร็วของ Apps Script
